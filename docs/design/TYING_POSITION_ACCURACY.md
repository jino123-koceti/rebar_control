# 결속 위치 검출 — 정확도 문제 정리

2026-11-05 작성. 2026-10-15~16 야외 데크플레이트 현장에서 **재캘리브레이션을
여러 번 했는데도 위치 정확도가 낮았던** 건을 중심으로, 지금까지 측정된 것과
아직 모르는 것을 나눠 적는다.

핵심 결론부터 — **그 현장의 문제는 캘리브레이션 모델이 아니었다.** 그래서
재캘리로 안 잡혔다. 모델을 다시 맞추는 것은 **모델이 틀렸을 때만** 듣는다.

---

## 1. 구조 — X 는 사실상 깊이축이다

```
① crossing_detector   화소 (u,v) + 깊이 z
   → 카메라 3D:  x=(u−cx)z/fx · y=(v−cy)z/fy · z
② tying_planner       스테이지 mm = A @ (x,y,z) + b
```

`stage_camera.yaml` 의 A 에서 **깊이 계수는 네 자세 모두 같다**:

```
A 3열 = [-1.557, -0.214, 0]      (X행, Y행, Z행)
```

카메라가 29° 기울어 있어 스테이지 X 와 카메라 깊이가 **−0.89 로 상관**된다.
그래서 **깊이 오차는 거의 전부 X 로 간다**:

| 깊이 산포 | X 산포 | Y 산포 |
|---|---|---|
| 8mm | **13.1mm** | 0.7mm |
| 0~1mm | 0~1.7mm | ≤1.4mm |

"Y 는 늘 ±5mm 인데 X 만 틀린다" 는 오랜 수수께끼가 이것이다.

⚠ 깊이를 **빼는** 것은 답이 아니다. 교차검증에서 깊이를 쓰는 쪽이 이겼다
(LOO 잔차 12.02 < 깊이열0 14.05 < 화소비례 20.22mm).

---

## 2. 현장에서 겹쳐 있던 것 — 셋

### 2.1 그때는 깊이가 **한 장**이었다

다중프레임 중앙값(`depth_frames`)은 **10-17 12:00** 커밋이다. 현장이 끝난
뒤다. 한 장만 쓰면 검출마다 10mm 대 난수가 X 에 얹힌다. 이것은 **표본 문제**라
모델을 다시 맞춰도 줄지 않는다 — 다음 검출은 또 새 난수를 가져온다.

### 2.2 짝이 섞여 있었다

10-12 에 2L 을 여러 번 빼고 꽂으며 카메라가 움직였는데 10-15 에야 알았다.
옛 짝과 새 짝을 섞어 적합하면 X 잔차 **2.58 → 11.84mm**(자세1 28.30mm).
`PLANE_SINCE='2026-10-15'` 로 옛 짝을 빼기 전까지는, **재캘리를 할수록 섞인
기하에 맞추고 있었다.**

### 2.3 주행 한 번에 ΔX 가 36mm 뒤집혔다 — 원인 미확정

2026-10-16 아침, **650mm 전진 하나 사이**:

```
전진 전:  -13.2 / -14.4 / -12.2 / -13.9   (자세 1·2·3·4)
전진 후:  +22.4 / +24.4 / +17.7 / +17.5
```

그리고 **650mm 후진해 제자리로 와도 안 돌아왔다.**

## 3. 2.3 의 원인 — 기록된 진단을 뒤집는다

기존 메모는 "지그·건 체결이 주행 진동에 밀렸다" 로 결론지었다. **그 근거가
논리적으로 틀렸다.** 근거는 이랬다:

> 깊이 369·460·564mm 에 걸쳐 ΔX 가 **같았으니 깊이 탓이 아니다**

깊이에 **일정한 치우침** Δz 가 생기면 `ΔX = −1.557 × Δz` 이고, 이는 실제
깊이가 얼마든 **같은 ΔX** 를 낸다. 즉 "여러 깊이에서 ΔX 가 같다" 는 깊이
원인을 **배제하는 증거가 아니라 부합하는 증거**다. 배제하려면 ΔX 가 깊이에
**비례**해야 하는데(배율 오차) 그건 보지 않았다.

숫자도 맞는다 — `36 ÷ 1.557 = 23mm`. **깊이가 23mm 치우치면 관측된 36mm 가
그대로 나온다.**

| 관찰 | 깊이 치우침 | 기구 밀림 | 기준점(호밍) 밀림 |
|---|---|---|---|
| 네 자세 동일하게 밀림 | ✅ 계수가 네 자세 공통 | ✅ | ✅ |
| 여러 깊이에서 ΔX 동일 | ✅ 거리 무관 | ✅ | ✅ |
| 후진해도 안 돌아옴 | ✅ 위치 의존 아님 | ✅ | ✅ |
| **기구가 락킹돼 있다** | ✅ 무관 | ❌ **모순** | ✅ 무관 |

주행부·결속부는 락킹돼 있고 카메라도 지그로 단단히 고정돼 있다(사용자 확인,
2026-11-05). **기구 밀림 가설은 그 사실과 모순된다.** 남는 후보는 둘이다:

**(a) 깊이 바이어스.** 2L 은 능동 IR 스테레오다. 직사광이 IR 대역을 덮으면
패턴 대비가 떨어져 서브픽셀 정합이 한쪽으로 치우친다. 유효 화소가 성글어지면
중앙값이 살아남은 화소(반사 강한 쪽)로 당겨진다 — **잡음이 아니라 치우침**이
된다. 야외·주간이라는 조건이 여기 걸린다. 온도 드리프트도 같은 방향이다.

**(b) 스테이지 기준점 밀림.** 위치는 호밍 기준값 대비 엔코더로 센다. 기준점이
밀리면(스톨·브레이크 미끄럼·멀티턴 이상) 로봇은 X 에 있다고 믿는데 실제는
X+36 이다. 자세 무관하고 되돌아오지 않는다. **체결을 조여도 안 고쳐진다.**

### 가리는 법 — 고정 표적 하나

주행 전후에 같은 평면(데크 바닥 등)까지의 **깊이 값 자체**를 잰다:

- 깊이가 ~23mm 변했다 → **(a) 깊이 바이어스**
- 깊이는 그대로인데 ΔX 만 변했다 → **(b) 기준점**

⚠ 아직 안 했다. 자율 고리 첫 실주행에 끼워 넣으면 같이 답이 나온다.

## 4. 별개로 남아 있는 것 — 뷰별 ±12mm

같은 자세 안에서도 **보는 위치에 따라** X 오프셋이 ±12mm 씩 다르다. X 오차의
82% 를 차지한다. 가설 다섯 개를 세워 전부 기각했다 — **다시 세우지 말 것**
(`rebar-calib-per-view-offset-unsolved`). 현재 대책은 모델을 고치는 것이
아니라 **카메라로 건 끝을 보고 닫는 것**이다 (`rebar-calib-close-loop-with-camera`).

## 5. 지금 쓰고 있는 대책

| 대책 | 효과 | 상태 |
|---|---|---|
| `depth_frames=5` 화소별 중앙값 | 반복오차 대부분 1mm 이하 | ✅ 적용 |
| 깊이 범위 필터 330~660mm | 평면 밖 검출이 엉뚱한 좌표로 가는 것 차단 | ✅ 적용 |
| 층 필터 `layer_ratio_min=0.35` | 하부근·허위 교차점 제거 | ✅ 적용 (2026-10-20) |
| `PLANE_SINCE` 로 옛 짝 배제 | 섞인 기하 방지 | ✅ 적용 |
| 정차마다 재검출 | 주행 드리프트를 매번 다시 잼 | ✅ 구조상 |

⚠ 층 필터가 **덤으로 깊이 품질까지 지킨다.** 봉 가장자리에 앉은 검출은
상부근 비율이 낮아 먼저 걸러지므로, 남은 점들의 깊이 창은 깨끗하다
(2026-11-05 실측: 창 폭 0~4mm, 25/25 화소가 상부근).
