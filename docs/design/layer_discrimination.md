# 배근 층 구분 (상부근 / 하부근) — 알고리즘과 이식 안내

> 3차년도 장비(`rebar_vision/layer_rank.py`)에서 돌고 있는 구현을 정리한 것이다.
> 2차년도 장비로 옮길 때 **무엇을 그대로 쓰고 무엇을 다시 재야 하는지**에 초점을 뒀다.

---

## 1. 무엇을 푸는가

교차점 검출 모델(RF-DETR)은 **층을 모른다.** 영상에 보이는 교차점을 전부 낸다:

- 상부근 ↔ 상부근 — **진짜 결속 대상**
- 상부근 ↔ 하부근 — 겹쳐 보일 뿐, 실제로는 닿지 않는 **허위 교차점**
- 하부근 ↔ 하부근 — 결속 대상이 아니다

허위 교차점에 건을 내리면 헛친다. 층은 **신뢰도로 갈리지 않는다** — 모델은
허위 교차점도 자신 있게 찾는다. 갈리는 것은 **높이(깊이)** 뿐이다.

> 참고로 3차년도에서 먼저 시도했다가 버린 방법: 교차점 **간격**(`grid_spacing_mm`)
> 으로 거르기. 결속 대상 상부근 교차점 2개를 신뢰도만 보고 버렸고, 원래 목적인
> 하부근 억제도 못 했다. 간격은 층의 대리 지표가 못 된다.

## 2. 알고리즘 — 두 단계

### ① 바닥 평면을 찾는다

무작위 3점으로 평면 후보를 1만 개 뽑고, 각 후보를 **(θ, φ, d)** 로 표현해
k-means(k=3)로 군집 지은 뒤 **가장 큰 군집**을 바닥으로 본다.

```
θ = atan2(ny, nx)        평면 법선의 방위각
φ = acos(nz)             법선의 극각
d = -(n · p)             원점에서 평면까지 거리
```

**왜 전체 최소제곱이 아닌가:** 철근이 화소의 상당 부분을 차지한다. 전체를 한
평면에 맞추면 평면이 철근 쪽으로 끌려간다. 군집은 **다수결**이라 안 끌린다.

**세 축 정규화가 필요하다.** θ·φ 는 라디안, d 는 mm 라 그대로 k-means 에 넣으면
d 가 지배한다. 세 축을 0~100 으로 정규화한다.

**법선 방향을 통일해야 한다.** `nz < 0` 이면 뒤집는다. 안 하면 같은 평면이 두
군집으로 갈린다.

### ①-b 평면을 내점으로 정밀화한다 (필수)

군집 중심은 (θ, φ, d) 공간에서 **평균한 값**이라 실제 어느 평면과도 다를 수 있다.
그대로 쓰면 바닥 화소의 평면거리가 **100mm 넘게 퍼진다** — 실제 층 차이(13~20mm)를
완전히 덮는다.

그래서 거친 평면의 **내점(거리 < 40mm)만** 골라 SVD 최소제곱으로 3회 다시 맞춘다.
*거친 선택(robust) + 정밀 맞춤(accurate)* 의 조합이다.

> 이 단계를 빼면 알고리즘이 **작동하지 않는다.** 2026-10-20 에 확인했다.

### ② 평면거리를 "골"로 가른다

모든 점의 평면거리를 히스토그램(10mm 칸)으로 만들고, **빈 구간**으로 띠를 나눈다.
띠를 거리 오름차순으로 세우면 그게 곧 층 번호다 (카메라 쪽이 가까우므로
0 = 가장 높은 층).

```
min_frac    = 0.02      최고 칸 대비 2% 미만이면 '빈 칸'
min_gap_mm  = 12.0      이보다 좁은 틈은 같은 층으로 본다
```

**⚠⚠ k-means 로 층을 나누면 안 된다.** 원본(한국공대 학생 구현)은 `LAYER_K` 개를
강제하는데, k-means 는 분산을 줄이므로 **점이 많은 층을 쪼개고 적은 층을 뭉갠다.**

실측 (2026-10-20): 바닥이 전체 화소의 62%(448k)인 장면에서 k=4 가
바닥을 둘로 쪼개고(−3 / +56) **레일과 상부근을 한 덩이로 묶었다**(−293 / −144).
그 결과 상부근 비율이 **전부 0.000** 이 됐다.

층은 개수가 아니라 **빈 구간**으로 갈린다 — 철근과 바닥 사이에는 늘 틈이 있다.
덤으로 **층 수를 미리 정할 필요가 없어진다.**

`min_gap_mm` 은 8~30mm 를 두 장면에서 훑어 **12** 로 정했다. 15 이상이면
상·하부근 사이 20mm 골이 메워져 한 층으로 합쳐진다.

## 3. ROI 를 두 개로 나눈다 (가장 중요한 설계)

```
fit_roi  : 평면을 **맞출** 범위   → 데크만. 좁게.
roi      : 층을 **매길** 범위     → 전체. 넓게.
```

둘을 같은 범위로 묶으면 둘 중 하나가 망가진다:

| | 증상 |
|---|---|
| 넓게 맞추면 | 데크 밖 배경(먼 벽)과 결속건이 평면을 끌어당긴다. **상부근 높이가 209~292mm (폭 83mm) 로 널뛰고** 띠 수도 3~5개로 바뀐다 |
| 좁게 매기면 | 경계 근처 검출의 둘레 원이 잘려 비율이 반 토막 난다 (실측: 진짜 교차점이 0.156 으로 허위처럼 보였다) |

`fit_roi` 로 데크만 남기면 **상부근 높이 폭 1mm, 띠 4개**로 매번 똑같이 붙는다.

**좌우 프레임 레일까지 빼야 한다.** 레일이 상부근과 비슷한 높이라 안 빼면 한 띠로
섞이고, 뒤의 `pick_rank` 가 **레일을 상부근으로 고른다.**

3차년도 값 (1280x800 기준):

```python
ROI_DECK = (280, 160, 720, 630)      # x, y, w, h
```

> 카메라가 프레임에 고정이라 이 창은 **자세와 무관하게** 유효하다.
> 캐리지에 달려 있다면 자세마다 다시 잡아야 한다 — 이식 때 먼저 확인할 것.

## 4. 층 번호를 박아 쓰면 안 된다

원본은 `TARGET_LAYER_RANK = 0` 으로 **0 번을 상부근**이라 못박는다.
3차년도 장비에서는 **프레임 레일이 철근보다 카메라에 가까워서 rank 0 이 레일**이다.
그대로 썼다면 레일을 결속 대상으로 골랐을 것이다.

그래서 **높이 구간으로 고른다**:

```python
up = pick_rank(info, lo_mm=120, hi_mm=300, prefer='high')
```

바닥 평면 **위쪽** 높이가 120~300mm 인 띠 중 가장 높은 것을 상부근으로 본다.
띠 개수는 장면에 따라 바뀌므로 호출부는 **항상** 이 함수로 고른다.

실측 예 (2026-10-20, 평면거리 — 음수가 카메라 쪽):

```
레일   -349mm      상부근 -186mm      하부근 -82mm      바닥 +3mm
```

## 5. 검출점 판정 — 둘레 원 비율

한 화소만 보면 안 된다. 키포인트가 철근 **사이**에 떨어질 수 있고, 깊이가 비어
있는 화소도 많다. 그래서 반지름 `layer_radius_px` 원 안에서 상부근 띠가 차지하는
**넓이 비율**을 본다.

```python
r = layer_ratio(rank, u, v, radius=50, target=up)
keep = (r >= 0.35)
```

**분모는 원 전체 넓이다** — 화면 밖도, 깊이 없는 화소도 분모에 든다. 그래야
"가장자리라 정보가 적다" 가 낮은 비율로 드러난다.

임계 **0.35** 의 근거 (2026-10-20, 사용자 정답 대조):

```
진짜 상부근 교차점   0.416 ~ 0.482
허위 · 하부근        0.177 ~ 0.252
                     ↑ 빈 구간 한가운데가 0.35, 양쪽 여유 0.07 이상
```

## 6. 1단 배근 구간 자동 건너뛰기

테스트베드가 1단·2단 **혼재**라 전역으로 켜고 끌 수가 없다:

- 끄면 → 2단 구간에서 허위 교차점에 건을 내린다
- 켜면 → 1단 구간에서 **검출이 전멸한다** (실측: 8개 전부 탈락, 비율 0.000~0.313)

가르는 근거는 **철근 띠 개수**다. 데크 평면에서 `layer_floor_mm`(50mm) 이상인
띠만 센다:

```
1단   층 중심 [160, 0]mm       → 철근 띠 1개 + 데크   → 필터 건너뜀
2단   층 중심 [160, 88, 0]mm   → 철근 띠 2개 + 데크   → 필터 적용
```

`_bands` 가 12mm 보다 좁은 틈을 같은 층으로 묶으므로, 상·하부근(70~75mm 간격)은
확실히 두 띠로 갈린다.

> **⚠ 2단인데 하부근이 가려져 안 보이면 1단으로 오인한다.** 그때는 허위 교차점이
> 통과한다. 의심되면 `single_layer_pass:=false` 로 끈다.

## 8. 2차년도 이식 체크리스트

### 그대로 쓸 수 있는 것
- `layer_rank.py` 전체 로직 (ROS 비의존 순수 모듈이다)
- 평면 탐색·정밀화·띠 나누기 상수

### 반드시 다시 재야 하는 것

1. **`ROI_DECK`** — 데크만 남기고 좌우 레일·위쪽 배경·결속건을 뺀다.
   확인 방법: 같은 자세에서 6회 반복해 **상부근 높이 폭이 몇 mm 인지** 본다.
   폭이 수십 mm 면 ROI 가 아직 넓다. 1~2mm 로 붙어야 한다.

2. **`pick_rank` 높이 구간** — 바닥 평면 위 상부근 높이를 먼저 측정한다.
   띠 중심(`info['centers']`)을 로그로 찍어 확인한다.

3. **`layer_ratio_min`** — 사람이 "진짜 상부근 교차점" 을 지정한 뒤, 진짜와
   허위의 비율 분포를 뽑아 **빈 구간 한가운데**를 잡는다. 3차년도는
   진짜 0.416~0.482 / 허위 0.177~0.252 였다.

4. **`layer_radius_px`** — 해상도가 다르면 비례로 환산하되, 반지름이 배근
   간격의 절반을 넘으면 옆 교차점이 섞인다.

5. **`MIN_GAP_MM`** — 2차년도 배근의 상·하부근 간격을 먼저 재고, 그 절반보다
   작게 잡는다.

### 먼저 확인할 전제

- **카메라가 프레임 고정인가, 캐리지 고정인가.** 캐리지면 `ROI_DECK` 를 자세마다
  잡아야 한다. 3차년도는 프레임 고정이라 하나로 끝난다.
  (확인법: 스테이지 X 를 200mm 넘게 움직이고 교차점의 **카메라 좌표**가
  변하는지 본다. 안 변하면 프레임 고정이다.)
- **레일이 철근보다 카메라에 가까운가.** 가까우면 rank 0 이 레일이다 —
  `pick_rank` 를 꼭 써야 한다.
- **깊이 유효 화소 비율.** 이 모듈은 깊이가 맞다고 가정한다. 유효 화소가 적으면
  평면 자체가 틀어진다. `info['valid']` 를 보고 적으면 쓰지 않는다.

## 9. 알려진 실패 모드

| 증상 | 원인 | 대처 |
|---|---|---|
| 모든 비율이 0.000 | `pick_rank` 가 레일을 골랐다 / k-means 로 층을 나눴다 | 높이 구간 확인, `_bands` 사용 |
| 상부근 높이가 매번 다르다 | `fit_roi` 가 넓다 (배경·건이 섞임) | 데크만 남긴다 |
| 가장자리 검출만 탈락한다 | 층을 **매기는** 범위가 좁다 | `roi=None`(전체)로 매긴다 |
| 1단 구간에서 검출 전멸 | 층 필터가 켜져 있다 | `single_layer_pass` 또는 `layer_ratio_min 0` |
| 바닥 거리가 100mm 넘게 퍼진다 | `_refit` 을 안 했다 | 내점 최소제곱 정밀화 추가 |
| 2단인데 허위가 통과 | 하부근이 가려져 1단으로 오인 | `single_layer_pass:=false` |
