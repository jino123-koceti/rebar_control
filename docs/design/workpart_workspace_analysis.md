## 0. 배경 / 목표

- 상부 작업부 4축: **X=0x144, Y=0x145, Z=0x146, Yaw=0x147** (CAN2, 1Mbps)
- `set_multiturn_save.py`(0x20 idx=0x04)로 **멀티턴 전원오프 저장**을 켜면
  0x92 멀티턴 절대각이 전원 사이클을 넘어 유지됨을 확인.
- 목표: 매 부팅 호밍 → **config 절대 레퍼런스 기반 절대 위치제어**로 전환,
  나아가 X/Y/Yaw를 **유기적(좌표→IK→동기이동)** 으로 움직이는 작업부 기구학.

### 기구 형상 (도면 + 실측 기준) — 확정 2026-05-29
- mover(XY 캐리지) 중심 → **yaw축 중심**: `(+185mm, 0)` (고정 오프셋, yaw 회전 무관)
- **결속포인트(TCP) = yaw축과 동일점** (top-view). 총구가 z로 `390mm` 내려가 투영이 yaw축에 일치 → 수평반경 0.
- **총구 손잡이(gun grip): yaw축에서 수평 230mm 돌출** — yaw 회전 시 이 막대가 쓸고 다니며 프레임에 충돌(도면 p5~7). 결속점 아님, **충돌 전용**.
- **yaw(자세)는 stage 위치를 안 바꿈** (TCP=yaw축이라 IK 헤딩 무관). 자세는 손잡이 방향 = 충돌 여부만 결정.
- yaw 자세: **이산 5개** (max/9시/12시/3시/min) 중 충돌 안전한 것 선택 → union = 작업영역 확대.
- 좌표계(도면 p8): `+x = 우`, `+y = 하(전진)`, `+z = 하`, yaw = z축 회전

## 1. 핵심 발견 — 0x92가 멀티턴 풀 누적 ✅

멀티턴 저장 **켜기 전** 2-샘플은 X 풀스트로크가 41.87°로 나와 wrapping 의심됐으나,
**켠 후** 측정에서 0x92가 명령 스케일과 동일하게 풀 멀티턴을 누적:

- X 풀스트로크 0x92 스팬 = **1842.2°** → `÷4.497(deg/mm) = 409.7mm ≈ 411mm` ✓
- → "출력축 43배 감속" 가설은 **wrapping 버그였고 폐기**. 0x92 = 명령축 동일 스케일.
- → 출력축이 풀스트로크에서도 멀티턴을 정상 누적하므로 **절대 좌표로 사용 가능**.

> 검증 잔여: 실제 **하드 전원차단** 후에도 0x92 유지되는지(persistence) 별도 확인 필요.
> (go/no-go 게이트)

## 2. 캘리브레이션 결과 (X·Y 확정)

| 축 | 0x92 @ MIN | 0x92 @ MAX | 스팬 | 스트로크(역산) | deg/mm | 부호 |
|---|---|---|---|---|---|---|
| **X** | `1818.69` (xMin/home) | `-23.53` (xMax) | 1842.2° | **409.7mm** | 4.497 | xMax로 갈수록 ↓ |
| **Y** | `-989.36` (yMin/home) | `+326.19` (yMax) | 1315.6° | **294.8mm** | yMax로 갈수록 ↑ |

부호는 메모리(`X 양수=xMin 방향`, `Y 양수=yMax 방향`)와 일치.

### 변환식 (base frame: xMin·yMin 코너 = 원점 (0,0))
```
x_mm = (1818.69 - 0x92_x) / 4.497
y_mm = (0x92_y - (-989.36)) / 4.462 = (0x92_y + 989.36) / 4.462
```
- stage 가용 범위: **x ∈ [0, 410]mm, y ∈ [0, 295]mm** (기계 리미트 기준)
- 메모리 "Y 288mm(결속기 간섭)"는 사용한계, 기계 스트로크는 ~295mm.
- 도면 p1~2의 X 400 / Y 230mm은 표기상 사용범위로 추정(기계값과 다름).

## 3. Yaw 분석

yaw 0x92 범위: home/min `-360°` ↔ max `+36°` → 스팬 **396°** (메모리 스펙 399°와 일치 ✓)

| 자세 | 방향(도면) | yaw 0x92 (실측) |
|---|---|---|
| max_limit | — | +36.1 |
| 9시 | -x (좌) | -31.5 |
| 12시(mid) | -y (상) | -166 |
| 3시 | +x (우) | -304 |
| home/min_limit | — | -360 |

### ⚠️ 헤딩 환산 비 (미확정)
9시→12시→3시는 각 물리 90° 회전인데 yaw 0x92는 ~136°/90°씩 변함:
- **0x92 1° ≈ 총구 0.66° 회전** (≈ 1.5 : 1)
- 원인: 실제 yaw 전동비 vs "o'clock" 눈대중 오차 — **미확정**
- 근사식: `gun_heading(+x기준) ≈ -0.652 × (0x92_yaw + 304)`
  - 검산: 9시(-31.5)→-177.7°≈180°(-x) ✓, 12시(-166)→-90°(-y) ✓

### 자세별 안전 Y 창 (x≈124mm 단면)
| yaw 자세 | +y 상한 | -y 하한 | 비고 |
|---|---|---|---|
| 3시 (+x) | 115mm (#6) | — | +y 가장 빨리 막힘 |
| home | 154mm (#5) | 0(기계) | |
| 12시 (-y) | — | 22mm (#3) | -y 거의 풀가용 |
| 9시 (-x) | — | 179mm (#7) | -y 크게 잠식 |
| max | 288mm (#9, ≈기계한계) | — | +y 거의 풀가용 |

### X 안전 한계 (y≈186mm 단면)
| yaw 자세 | +x 상한 | 비고 |
|---|---|---|
| max | 410mm (#0, 기계한계) | 충돌 없음 |
| 12시 | 236mm (#2) | +x 막힘 |

### 해석
- **+y 안전상한이 yaw에 강하게 종속**: 3시(115) < home(154) < max(288).
  총구가 +y로 뻗는 자세일수록 일찍 충돌.
- **-y 안전하한도 종속**: 9시(179) ≫ 12시(22).
- → 좌표→IK 후 **"이 yaw에서 이 (x,y)가 안전한가" 검사 필수** (도면 p5~7).
