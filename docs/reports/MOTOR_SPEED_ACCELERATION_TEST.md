# RMD X4-10 스테이지 모터 속도/가속도 실험 보고서

**실험일시**: 2026-03-09
**대상 모터**: RMD X4-10 × 4축 (X: 0x144, Y: 0x145, Z: 0x146, Yaw: 0x147)
**CAN 인터페이스**: can2
**환경**: Jetson Orin 기반 철근 결속 로봇 상부 XYZ 스테이지

---

## 1. 모터 사양

| 항목 | 값 |
|---|---|
| 모터 모델 | RMD X4-10 |
| 감속비 | 12.6:1 |
| 정격 RPM (모터축) | 238 rpm |
| 정격 각속도 (모터축) | 1,428 dps |
| 이론 최대 출력축 속도 | 1,428 ÷ 12.6 ≈ **113 dps** (무부하 이론값) |
| 제어 명령 | 0xA4 (Position Control with Speed Limit) |
| 속도 단위 | 1 dps/LSB (출력축 기준, uint16) |

> **참고**: 정격 238rpm은 모터축 기준이며, 출력축(감속기 후단) 속도는 감속비로 나눈 값이 이론적 최대치. 단, 실제로는 모터가 정격 이상 출력 가능하여 출력축 ~230dps까지 도달 확인됨.

---

## 2. 모터 내부 가감속 파라미터 (0x42 읽기)

4개 스테이지 모터 모두 동일한 설정:

| 파라미터 (function_index) | 설명 | 값 |
|---|---|---|
| 0x00 | Position Planning Acceleration | 5,000 dps/s |
| 0x01 | Position Planning Deceleration | 5,000 dps/s |
| 0x02 | Speed Planning Acceleration | 5,000 dps/s |
| 0x03 | Speed Planning Deceleration | 5,000 dps/s |

- 0xA4 위치 제어 시 Position Acceleration ≠ 0이면 **사다리꼴 속도 프로파일** 모드로 동작
- 설정값은 "허용 상한"이며, 실제 가속도는 부하/토크 한계에 의해 제한됨

## 3. 속도 튜닝 실험

### 3.1 실험 조건
- **축**: X축 (0x144)
- **이동 거리**: 800° (약 178mm)
- **서비스 중지 후 단독 테스트** (CAN 간섭 제거)
- **측정 방식**: 0xA4 명령 후 0x9C(상태요청) 반복 전송, 응답의 speed 필드 기록

### 3.2 명령 속도별 실측 결과

| 명령 속도 (dps) | 실측 최대 출력축 속도 (dps) | 800° 이동 시간 (s) | 비고 |
|---|---|---|---|
| 300 | ~215 | 약 3.5 | 정상 도달 |
| 400 | ~230 | 2.90 | **포화점** - 최적 설정 |
| 500 | ~230 | 2.90 | 400dps와 동일 (포화) |
| 800 | ~230 | 2.90 | 400dps와 동일 (포화) |

**결론**: 400dps 이상 명령해도 출력축은 ~230dps에서 포화. 400dps가 최적 명령값.

### 3.3 속도 포화 원인 분석

```
명령 400dps × 감속비 12.6 = 모터축 5,040 dps (840 rpm)
정격 238rpm 대비 3.5배 → 모터 PI 컨트롤러가 전류(토크) 제한
실제 출력축 230dps × 12.6 = 모터축 2,898 dps (483 rpm)
→ 정격의 약 2배에서 안정 동작
```

## 4. 가속도 프로파일 실측

### 4.1 실험 조건
- **명령**: 400dps, 800° 이동
- **샘플링**: 0x9C 상태 요청 (~50ms 간격)

### 4.2 속도-시간 프로파일 (사다리꼴)

```
속도(dps)
  400 |          _______________
      |         /               \
  300 |        /                 \
      |       /                   \
  200 |      /                     \
      |     /                       \
  100 |    /                         \
      |   /                           \
    0 |__/                             \__
      +---+---+---+---+---+---+---+---+--→ 시간(s)
      0  0.3 0.6 0.9 1.2 1.5 1.8 2.1 2.9

      |가속구간|   정속 구간    |감속구간|
       ~1.0s      ~1.2s        ~0.7s
```

### 4.3 구간별 분석

| 구간 | 시간 | 속도 변화 | 실효 가속도 |
|---|---|---|---|
| 가속 | 0 → ~1.0s | 0 → 400 dps | ~400 dps/s |
| 정속 | ~1.0 → ~2.2s | ~400 dps 유지 | - |
| 감속 | ~2.2 → 2.9s | 400 → 0 dps | ~570 dps/s |

- **설정 가속도**: 5,000 dps/s
- **실효 가속도**: ~400 dps/s (설정의 8%)
- **원인**: 모터 토크 한계가 가속도를 제한. 가감속 파라미터를 더 올려도 개선 불가.

## 5. 실제 결속 사이클 적용

### 5.1 XY 스테이지 이동 시간 추정

| 이동 거리 | 명령 속도 | 예상 소요 시간 |
|---|---|---|
| 100mm (450°) | 400 dps | ~1.8s |
| 200mm (900°) | 400 dps | ~3.3s |
| 300mm (1350°) | 400 dps | ~4.7s |
| 최대 411mm (1849°) | 400 dps | ~6.5s |

> 이동시간 ≈ (이동각도 / 230) + 1.5s (가감속 오버헤드)

### 5.2 최종 설정값

```yaml
# tying_orchestrator.yaml
stage_max_speed_dps: 400.0   # 출력축 포화점 기준 최적값
```

---

## 6. 요약 및 권장사항

1. **XY 속도**: 400dps 명령이 최적 (출력축 ~230dps 포화)
2. **가감속 설정**: 5,000 dps/s 유지 (증가시켜도 토크 한계로 실효 변화 없음)
3. **속도 개선 불가**: 모터 물리적 한계 도달. 추가 개선은 경량화 또는 상위 모터 적용 필요
4. **추가 최적화 여지**:
   - Z축 속도 튜닝 (현재 200dps)
   - settling_time 단축 (현재 WAITING_SETTLE 0.3s)
   - 포인트 간 경로 최적화 (TSP 등)
