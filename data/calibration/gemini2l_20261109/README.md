# Gemini 2L 캘리브레이션 백업 (2026-11-09)

교차점 카메라를 **Gemini 2L → Gemini 336L** 로 교체하기 직전 상태다.
336L 이 기대만 못하면 이 두 파일을 `data/calibration/` 로 되돌리면 된다.

## 이 시점의 품질
- 짝 22개 (깊이 ≤660 로 거른 뒤 20개), 장비 5곳
- 저장 모델 성분별 잔차  X 2.71 / Y 2.16 / Z 3.36mm  (RMS 2.79, 최대 7.33)
- **교차검증(leave-one-out) 4.89mm** ← 새 교차점에서 기대할 실제 오차
  자세별 4.34 / 3.73 / 5.77 / 4.98mm
- 결속 실적 4/5 (2026-11-09), 성공한 점의 Z 오차 0.12~0.19mm

## 교체 후 확인 순서
1. **깊이 정확도부터** — 350~660mm 에서 줄자와 대조. 2L 은 약 4% 였다.
   여기서 2L 보다 못하면 되돌리는 것이 맞다.
2. **A 가 살아남았는지** — 자세당 2점씩 8점만 받아 `A` 는 고정한 채 `b` 만 재적합.
   잔차가 3mm 대면 A 유지, 10mm 넘게 벌어지면 22짝 전부 재취득.
   (지그 규격이 같아 광학중심이 비슷하면 A 가 살아남을 수 있다)
3. **검출 성능** — RF-DETR 은 2L 영상으로 학습됐다. 화각·해상도가 달라지면
   검출이 나빠질 수 있으니 같은 장면에서 검출 수·신뢰도를 비교할 것.
4. 층 필터 임계(0.35), 결속 깊이 범위(330~660), USB 대역폭도 다시 봐야 한다.
